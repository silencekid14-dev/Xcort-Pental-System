PENTAL Virtual Prototype

Select a component. Fully offline — no external libraries. Drag to rotate the stack. Shows physical topology, PMPW / TSV data paths, ALUs and the quantitative claims from the architecture specs.

PCPU
4-layer 3D-stacked matrix processor. 16 cores, 64 ALUs, PMPW grid, Throlter sheets, TSV elevators. Target 5.0–5.2 GHz, 80–160 W.
PRAM
Cross-point memory stack with 4 096 dedicated TSV bitlines. Direct voltage-coordinate addressing. ~4.0 ns latency, 3.07 TB/s (16 GB banked).
PGPU
Hybrid STET/DTET graphics engine. 16 384 independent ALUs across 4 layers. Physical divergence isolation. 6.0 GHz, ~300 W core.
